# E-Portfolio สำหรับครูผู้สอนด้านเทคโนโลยีและการเขียนโปรแกรม

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สำหรับครูผู้สอนด้านเทคโนโลยีและการเขียนโปรแกรม ออกแบบด้วยโทนสีส้ม-ขาว รองรับทั้งคอมพิวเตอร์และโทรศัพท์มือถือ

## ✨ คุณสมบัติของเว็บไซต์

- หน้าแรกแนะนำตัว
- หน้าแนะนำประวัติและข้อมูลส่วนตัว
- หน้าผลงานพร้อมรายละเอียดและลิงก์
- หน้ากิจกรรมและประสบการณ์
- เมนูนำทางที่รองรับมือถือ
- ปุ่มเชื่อมต่อ GitHub
- ส่วนท้ายแสดงช่องทางติดต่อ

## 📁 โครงสร้างไฟล์

```text
e-portfolio/
├── index.html
└── README.md
```

## 🚀 วิธีเปิดใช้งาน

1. ดาวน์โหลดไฟล์ `index.html`
2. เปิดไฟล์ด้วยโปรแกรมแก้ไขโค้ด เช่น Visual Studio Code
3. ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดเว็บไซต์ผ่านเว็บเบราว์เซอร์

ไม่จำเป็นต้องติดตั้งโปรแกรมเพิ่มเติม

## ✏️ การแก้ไขข้อมูล

เปิดไฟล์ `index.html` แล้วแก้ไขข้อมูลตัวอย่างให้เป็นข้อมูลของตนเอง เช่น

- ชื่อและนามสกุล
- ประวัติส่วนตัว
- ประวัติการศึกษาและการทำงาน
- ผลงานและโครงการ
- กิจกรรมที่เข้าร่วม
- ลิงก์ GitHub และช่องทางติดต่อ

อย่าลืมเปลี่ยนลิงก์ตัวอย่าง เช่น `your-username` และ `teacher@example.com` ให้เป็นข้อมูลจริงด้วย

## 🌐 การเผยแพร่ผ่าน GitHub Pages

1. สมัครหรือเข้าสู่ระบบ GitHub
2. สร้าง Repository ใหม่
3. อัปโหลดไฟล์ `index.html` และ `README.md`
4. เข้าเมนู **Settings**
5. เลือก **Pages**
6. ในส่วน Build and deployment เลือก **Deploy from a branch**
7. เลือก Branch เป็น `main` และ Folder เป็น `/(root)`
8. กด **Save**
9. รอสักครู่ เว็บไซต์จะเผยแพร่ผ่านลิงก์ GitHub Pages

ตัวอย่าง URL:

`https://ชื่อบัญชี.github.io/ชื่อ-repository/`
